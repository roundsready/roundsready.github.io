Privacy Policy

Applies to: Rounds Ready Uploader · Last updated: 6 October 2026

What the app is

Rounds Ready Uploader is a private tool used only by the owner of the Rounds Ready YouTube channel (@RoundsReadyRx). It publishes the channel's own educational videos. It is not offered to the public.

What data it accesses

With the owner's permission, given through Google sign-in, the app uses the YouTube Data API to:

  • upload videos to the owner's channel and set their title, description, tags and privacy status;
  • set video thumbnails and upload caption files;
  • add videos to the channel's playlists.

The app does not read, collect or store viewer data, comments, subscriber lists, contacts, email or any other personal information.

How data is stored

The only stored item is the OAuth access token, kept on the owner's private server so uploads can run. It is never shared, sold or sent to any third party, and it is not used for advertising.

Google API Services

Rounds Ready Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Security → Third-party connections. The stored token is then deleted from the server.
